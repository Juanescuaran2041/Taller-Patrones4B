"# Taller-Patrones4B" 
# Patron AbstractFactory:
Permite crear varios tipos de terminales a partir de una única fabrica de terminales, es útil para reutilizar evitar compartir responsabilidades únicas entre los tipos de terminales

# Patron Factory Method:
Permite obtener varias unidades de carga a partir de un método protegido de fabrica

# Patron Builder:
Permite instanciar una clase mediante métodos propios para evitar colocar mal los atributos, en orden inverso o crear clases sin sentido
